# Security Policy

## Supported Versions

Security fixes are applied to the latest release on the `main` branch.

## Reporting a Vulnerability

Please do not open a public issue for a security vulnerability. Use GitHub's
private vulnerability reporting feature for this repository or contact the
repository maintainers privately.

Include:

- affected version or commit
- reproduction steps
- impact assessment
- any suggested mitigation

## Medical and Privacy Notice

This project is intended for research, education, and algorithm evaluation. It
is not a medical device and must not be used for diagnosis or treatment.

Never commit real patient data, DICOM files, clinical reports, credentials, or
identifiable medical images to this repository. Use de-identified public
research data only.
